Synchromy for Windows
Designed by Etienne Mineur, etienne.design/tools/synchromy

Generative drawing and music, a tribute to Norman McLaren. No connection, no installation: the program computes the picture and the music live.

THE APP: Synchromy.exe
Double-click it. Synchromy opens full screen on the main display.
  Esc: quit
  F or F11: full screen or window
  M: mute or restore the music
  N: new picture

THE SCREEN SAVER: Synchromy.scr
Right-click Synchromy.scr, then "Install". Windows opens the screen saver settings with Synchromy selected.
The "Settings" button sets the music and its volume. The slightest mouse or keyboard movement stops it.
To keep it, first copy Synchromy.scr to a folder that will not move (Documents, for example), then "Install" it from there.

MUSIC
Each picture has its own music. From time to time, "make me dance" takes over: a set of 90s UK jungle, around 120 bpm (sometimes up to 160), made of four-minute tracks mixed like a DJ would, in five styles: ragga, atmospheric, darkside, amen, jump-up. The nine op art patterns are there too.

SOUND
Stereo, or 5.1 and 7.1 if Windows reports such a speaker layout (Settings > Sound > output device > Format / Speaker configuration).

FIRST LAUNCH
The program is not signed with a Windows certificate: Windows may show "Windows protected your PC". Click "More info", then "Run anyway". It only asks once.

Windows 10 or 11, 64-bit (PCs with ARM processors run it in emulation).
